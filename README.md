# Resume Bullet Generator

Write strong resume bullets from vague experience

## Overview
Resume Bullet Generator is a digital prompt pack that helps students turn vague class, internship, volunteer, or project experience into clear, action-oriented resume bullets. It includes action-verb lists, STAR framing prompts, and questions that help uncover metrics such as hours saved, people reached, or results improved. It is a writing aid, not a guarantee of interviews or job offers.

## Use cases
- A student has only "helped with club events" and needs a bullet showing planning, attendance, and impact.
- An internship description is a list of tasks, and the student wants to frame work around a specific problem, action, and result.
- A volunteer role has no obvious numbers, so the prompts help estimate scope, frequency, or audience size honestly.

## How to use
1. Download the files and open the prompt pack in your preferred notes or writing app.
2. Paste a vague experience into the STAR prompts and answer the metric-finding questions without exaggerating.
3. Select an action verb, draft two bullet options, then edit for accuracy and your resume's style.

## What is included
- Action verb library
- STAR framing prompts
- Metric-finding questions
